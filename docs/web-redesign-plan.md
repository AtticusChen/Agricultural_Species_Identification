# 薇迹识别工作台改版

用户：模型训练完成后重新设计简陋的识别网站。2026-09-14。

## 目标与视觉

面向不懂编程的现场使用者，制作可真实使用的电脑端识别工作台，不改训练数据和默认模型。用户补充：无需手机布局，验收以电脑1440×1000、笔记本1280×800为准。保留线上V3/.88；V4.1未通过误报门槛，不随UI改版偷换。

视觉选择：自然观察站 / 清爽专业的植物工作台。浅灰白画布、深森林绿、少量青柠色点缀；窄侧栏、真实薇甘菊照片、精细线性图标、大留白与清晰的结果画布。不用外部CDN或新前端构建框架，保持跨设备部署简单。

## 语义与隐私

得分不是准确率；参考区域不是植株数或精确边界；present与区域个数独立。未检出不等于不存在。拒绝假统计、假成功状态和写死推理结果。

图片上传当前识别服务，记录只放当前页面内存；刷新后清空，不默认存浏览器持久存储。最多10张、每张20MB、总80MB；顺序请求避免服务器并发拥堵。模型/默认阈值读实际健康接口，不额外传入四舍五入的默认阈值。
