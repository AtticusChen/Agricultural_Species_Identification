# Phase 0 试标协议

## 目的

用 50 张近景图和 30 张无人机图验证最终标注口径，而不是追求一次完成全部标注。试标需要回答：

1. “连续薇甘菊株丛框”是否能被不同标注者稳定复现；
2. 无人机斑块使用矩形框还是语义掩膜更一致；
3. 近似种文件夹中是否混有薇甘菊；
4. 哪些样本必须进入植物专家复核队列。

## 试标包结构

运行 `uv run mikania-data pilot ...` 后生成：

```text
artifacts/pilot_v1/
├── images/
│   ├── ground/   # 50 张，符号链接到原图
│   └── uav/      # 30 张，符号链接到原图
├── labels/
│   ├── ground/   # YOLO .txt
│   └── uav/      # 单通道 PNG 掩膜
├── manifest.csv
├── excluded_bad_images.csv  # 若审计发现不可读图片
└── summary.json
```

不得改名、移动或覆盖 `data/` 中的原始图片。`manifest.csv` 是试标包与原始数据之间的追踪表。

两名标注者必须使用彼此隔离的标签和清单副本，分别记为 `annotator_a`、`annotator_b`；不得查看或覆盖对方结果。完成独立标注后，另建 `adjudicated` 目录保存专家裁定版，原始两版标注永久保留用于一致性分析。

## 近景图规则

- 主类别只有 `mikania=0`。
- 一个框表示一处肉眼可分的连续薇甘菊株丛；被明显的空地或其他植物隔开时分框。
- 框贴合可见薇甘菊外缘，避免大面积背景。
- 近似种图也必须逐张检查；确认无薇甘菊时保留空标签，不能凭文件夹名直接生成空标签。
- 拿不准物种时不猜测，在清单中将 `review_status` 改为 `expert_review` 并填写 `expert_note`。
- 遮挡后仍能可靠确认且可见面积不少于约 30% 才标。

每名标注者独立完成同一批 50 张图。比较同图框匹配后的 IoU、框数量差异、漏标率、争议率和每图耗时。

## 无人机图规则

- 使用二值语义掩膜：背景为 0，确认的薇甘菊冠层为 1（保存 PNG 时可用 255 显示）。
- 标的是可辨认的冠层覆盖斑块，不追踪不可见的藤茎，也不推测树冠下的范围。
- 阴影、过曝或分辨率不足而不能确认的边界进入不确定区记录，不强行补全。
- 保留完整大图坐标；正式训练切片必须在原图/航次完成分组之后进行。

每名标注者独立完成同一批 30 张图。比较 Dice、IoU、Boundary IoU、面积差异和每图耗时。

## 通过条件

- 近景框：匹配目标的标注者间中位 IoU 建议不低于 0.75，图像级物种判定一致率不低于 90%。
- UAV 掩膜：图像级 Dice 建议不低于 0.80；若边界一致性明显低但面积一致，可进一步定义允许的模糊边界带。
- 专家复核后仍无法稳定定义的样本不进入训练或测试。
- 若连续株丛框一致性不达标而掩膜明显更稳定，近景主任务改为实例/语义分割。

通过试标后，冻结标注规范 v1.0、类别表、采集组清单和测试集，再开始首轮正式标注与训练。
