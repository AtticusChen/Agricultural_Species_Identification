# 薇甘菊识别系统便携版 v2.1.0

这是一个不需要 Docker、不连接训练服务器、也不要求用户提前安装 Python 的笔记本部署包。解压后可直接看到“程序源码”“模型文件”和 `runtime`（安装与运行脚本）目录。模型、网页和推理程序均在本机运行；首次安装环境时需要网络，之后可以离线识别图片。

## 运行要求

- 64 位 Windows 10/11、macOS 14 或更高版本，或 Ubuntu 22.04 及同类 x86_64 Linux；
- 建议至少 4 GB 可用内存、2 GB 可用磁盘；
- 首次安装需要连接互联网下载独立 Python 运行时和识别组件；
- 普通用户权限即可，不需要管理员权限。

安装程序使用固定版本的独立环境工具，运行时、依赖和缓存均与系统程序隔离。删除整个交付文件夹即可卸载，不会修改系统 Python。

## Windows

1. 解压本 ZIP，不能直接在压缩包预览中运行。
2. 双击 `01-一键安装-Windows.bat`，等待显示安装完成。
3. 双击 `02-启动识别系统-Windows.bat`。
4. 浏览器将自动打开 `http://127.0.0.1:18080`。

## macOS

1. 解压本 ZIP。
2. 首次使用时右键 `01-一键安装-macOS.command`，选择“打开”。
3. 安装完成后双击 `02-启动识别系统-macOS.command`。
4. 浏览器将自动打开 `http://127.0.0.1:18080`。

如果系统拦截脚本，可在终端进入本目录后运行：

```bash
chmod +x 01-一键安装-macOS.command 02-启动识别系统-macOS.command
./01-一键安装-macOS.command
./02-启动识别系统-macOS.command
```

## Linux

```bash
chmod +x 01-一键安装-Linux.sh 02-启动识别系统-Linux.sh
./01-一键安装-Linux.sh
./02-启动识别系统-Linux.sh
```

## 使用方式

1. 选择或拖入 JPG、PNG、WebP 植物照片；
2. 点击“开始识别”；
3. 页面显示“识别到薇甘菊”或“未识别到薇甘菊”；
4. 绿色框为模型识别出的疑似薇甘菊区域；
5. 关闭启动窗口或按 `Ctrl+C` 停止系统。

## 允许同一局域网的其他设备访问

默认只允许本机访问。需要让同一局域网中的手机或电脑访问时：

- Windows：双击 `03-启动局域网共享-Windows.bat`；
- macOS：双击 `03-启动局域网共享-macOS.command`；
- Linux：运行 `03-启动局域网共享-Linux.sh`；
- 启动窗口会显示同一局域网设备可使用的地址。按系统提示允许程序通过防火墙。

不要将未设置身份认证的服务直接暴露到公网。

## 常见问题

- 环境下载失败：确认首次安装时可以访问互联网，然后重新运行“一键安装”。
- 安装窗口被安全软件拦截：允许本交付目录中的安装脚本运行，或请单位技术人员协助确认。
- 端口被占用：关闭已运行的识别窗口，或设置环境变量 `MIKANIA_PORT` 为其他端口。
- 模型校验失败：文件复制不完整，请重新解压 ZIP。
- 首张图片较慢：首次识别需要加载模型，后续图片会更快。
- Windows 双击后窗口立即关闭：确认已经“全部解压”，然后运行 `04-Windows故障诊断.bat`；新版入口会停留并显示具体错误。
- 需要技术支持：将 `runtime/logs` 中对应系统的安装日志一并提供。

## 说明与限制

- 本系统只用于辅助筛查，“未识别到”不等于专业确认不存在薇甘菊；
- 模型详情见 `模型文件/mikania-yolo26s-v2/model_card.md`；其中 `model.onnx` 用于网页识别，`model.pt` 用于继续训练和重新导出；
- 模型由 Ultralytics YOLO 训练和导出，对外闭源或商业使用前需确认适用许可；
- 根目录 `交付内容与文件清单.txt` 说明源码、模型和数据范围；`交付文件SHA256.txt` 可用于检查包内文件是否完整。
