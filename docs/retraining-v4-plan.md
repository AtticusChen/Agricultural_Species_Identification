## 冻结对照与选择规则

1. V3 原部署组合，整图 384、局部 320、1280 瓦片/20% 重叠、0.25 整图 + 0.75 第二高局部、阈值 0.88，作为固定回归基线。
2. G1：通用 YOLO26s-cls 初始化，包含全图内容的方形填充输入 512，联合训练地面和已筛查 UAV 图像，AdamW，80 epoch 上限，patience 20。
3. G2：V3 整图权重初始化，同一新数据，512 输入，小学习率微调；检验增加数据能否保持旧地面能力。
4. G3：V3 局部权重初始化，320 输入，旧地面局部及已复核 UAV 局部，避免把背景当成目标。
5. 候选决策仅比较整图、0.25/0.75 组合和 0.5/0.5 组合；在 val 上选阈值并要求每个具备负样本的域误报率不超过 10%。无满足实用表现的候选则保留 V3 部署，不自动替换。

- 旧内部测试和外部 100 张已经参与过多轮模型选择，全部是历史回归开发集；继续保持不训练，但不称全新盲测。
- 无人机优先按物理地点及连续拍摄组留出；检查同地点地面照片交叉，不能仅依据文件名随机拆分。
- 先冻结候选与阈值，后评价测试；同时记录 TP/FN/FP/TN、分域指标和拍摄组平均表现。
- 单类集合只报告可计算指标；没有正样本时灵敏度为空，没有负样本时误报率为空，平衡准确率需双类均存在。
- 图像判定与粗区域提示分开；没有可靠完整框/掩膜时不报告新的 mAP 或轮廓覆盖精度。
