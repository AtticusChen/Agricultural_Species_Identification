# 薇甘菊智能识别实验设计 v0.1

日期：2026-08-01  
阶段：讨论稿；在试标完成前不冻结模型结构和性能目标

## 1. 总体结论

建议把项目定义为“近景单类检测 + 无人机斑块分割 + 统一风险分析界面”的双场景系统。论文的核心问题是跨采集组泛化和近似种误检，不是简单替换一个 YOLO 版本；专利候选则围绕形态线索监督、困难负样本、跨尺度推理和不确定性复核形成可执行的闭环流程。

## 2. 任务边界

### Track A：地面近景目标检测

输入为手机/相机 RGB 图，输出连续薇甘菊株丛的边界框、置信度和辅助属性。主类别只有 `mikania`。这是首个可训练、可部署的 MVP。

### Track B：无人机斑块语义分割

输入为无人机 RGB 图或正射拼接图，输出薇甘菊冠层掩膜、覆盖像素数；有 GSD/航高标定时进一步输出面积。无人机图不以“单株”为标注单位。

### Track C：统一界面与分析

支持单图、批量文件夹和无人机图；展示框/掩膜、阈值调节、置信度、疑似区域、近似种误报、覆盖面积、模型版本和导出报告。界面只消费冻结的推理接口，不参与训练逻辑。

## 3. 数据协议

### 3.1 试标门

先选 50 张近景图和 30 张无人机图，至少两名标注者独立标注。记录：每图耗时、框/掩膜数量、标注者 IoU、类别争议率、专家裁定率。若连续株丛框的一致性明显低于掩膜，则 Track A 可升级为实例/语义分割而不是勉强维持检测框。

### 3.2 正式划分

- 开发集：按采集组划分 train/val，禁止同一连拍序列或同一航线相邻帧跨集合。
- 内部测试集：在训练前冻结，后续所有模型共用。
- 外部测试集：来自新地点或新日期，项目完成前只评估有限次数。
- 数据增强仅作用于训练集；验证/测试保持原图，只允许确定性的缩放/切片。

### 3.3 标注质控

- 100% 自动格式检查；20% 双人复核；存疑物种 100% 专家裁定。
- 近景负样本必须确认“没有薇甘菊”，不能把近似种文件夹机械转成空标签。
- UAV 原图先分组后切片；保存 `source_image_id`、`flight_id`、切片坐标，保证可追溯。

## 4. 模型与研究假设

### 4.1 强基线

| 任务 | 基线 | 目的 |
|---|---|---|
| 近景检测 | YOLO26n/s | 当前实时检测与部署基线，包含小目标友好的 P2 架构选项 |
| 近景检测 | Faster R-CNN ResNet50-FPN v2 | 与原方案同属两阶段方法，但参数和算力更适合当前数据规模 |
| 近景检测 | RT-DETRv2-R18/R50 | NMS-free Transformer 检测基线 |
| UAV 分割 | U-Net | 经典低复杂度基线 |
| UAV 分割 | DeepLabV3+ | 与既有薇甘菊 UAV 研究对齐 |
| UAV 分割 | SegFormer-B0/B2 | 现代轻量 Transformer 分割基线 |

不建议直接把 Faster R-CNN + ResNet101 + 4×A100 固定为唯一方案：现有数据仅 885 张且无标注，ResNet101 容易形成过高训练成本和过拟合风险；它可以保留为论文对照，而不是默认主模型。

### 4.2 候选方法：形态线索与困难负样本协同学习

暂用名：`Mikania-Cue`。候选组成如下：

1. 单类检测/分割主头，避免叶、花、茎、整株的嵌套类别冲突。
2. 形态属性辅助头，预测叶形可见、花簇可见、攀援覆盖和物候状态；推理时可关闭或仅用于解释。
3. 困难负样本对比学习/困难样本采样，对假臭草、三叶鬼针草、火炭母、水蓼、大青叶等建立显式负样本约束。
4. 尺度适配：近景检测比较标准头与 P2/高分辨率；UAV 使用重叠切片、边界加权融合和整图上下文校准。
5. 不确定性复核：高熵、低间隔或多增强不一致样本自动进入人工复核队列，用于主动学习下一轮。

“小波 + 边缘细化”不作为主创新，因为 2026 年 WaveEdgeNet 已在薇甘菊 UAV 分割中采用相近方向。

## 5. 分阶段实验矩阵

### Phase 0：标注与数据可行性

| ID | 实验 | 判定 |
|---|---|---|
| D0 | 近景连续株丛框双人试标 | IoU、一致率、耗时、争议率 |
| D1 | 近景部位框双人试标 | 与 D0 比较，验证五类旧方案是否可复现 |
| D2 | UAV 框 vs 斑块掩膜试标 | 一致性和面积误差；确定 Track B 标签 |
| D3 | 感知重复/相邻帧聚类 | 形成 `group_id`，冻结划分 |

### Phase 1：可复现基线

| ID | 模型 | 输入 | 目的 |
|---|---|---|---|
| B0 | YOLO26n | 640/960 | 快速烟雾测试和界面模型 |
| B1 | YOLO26s | 960/1280 | 主实时检测基线 |
| B2 | Faster R-CNN R50-FPN v2 | 短边 800/1024 | 两阶段精度基线 |
| B3 | RT-DETRv2-R18/R50 | 640/960 | 端到端检测基线 |
| S0 | U-Net | 1024 patch | UAV 分割下限 |
| S1 | DeepLabV3+ | 1024 patch | 既有工作对齐 |
| S2 | SegFormer-B0/B2 | 1024 patch | UAV 现代基线 |

所有核心模型至少运行 3 个随机种子；同一数据划分、同一预训练来源、同一训练预算。先在本地完成代码与小样本验证，正式矩阵使用已核验的 6×RTX 5090（单卡约 32 GB）服务器；第一轮基线单卡运行，只有多随机种子并行或大模型/大图对比确有必要时再扩展多卡。

### Phase 2：精度提升与消融

| ID | 相对 B1/S2 的变化 | 验证问题 |
|---|---|---|
| A1 | + 困难负样本平衡采样 | 是否降低近似种假阳性 |
| A2 | + 形态属性辅助头 | 是否提升非花期/遮挡召回 |
| A3 | + 对比学习约束 | 是否扩大薇甘菊与近似种特征间隔 |
| A4 | + P2 或高分辨率切片 | 是否提升小目标 AP/小斑块 Dice |
| A5 | + 不确定性主动学习一轮 | 同等新增标注量下是否优于随机采样 |
| A6 | A1+A2+A3+A4 | 完整候选方法；与最强简单基线比较 |

### Phase 3：鲁棒性与部署

- 分层评估：开花/非花期、近景/UAV、设备、日期、阴影、遮挡、目标尺寸和近似种。
- 外部地点评估；严禁用外部测试集选择阈值或模型。
- 导出 ONNX/CoreML；若面向 NVIDIA 边缘端再做 TensorRT。记录相同设备、相同 batch、含/不含预处理的延迟。
- 量化或蒸馏必须报告精度变化，不能只报告速度提升。

## 6. 指标与统计

### 近景检测

- COCO mAP@0.5:0.95、AP50、Precision、Recall、F1。
- 小/中/大目标 AP；近似种子集假阳性率；每图假阳性数（FPPI）。
- 固定验证集选阈值后，报告测试集 Recall@固定 FPPI。

### UAV 分割与面积

- mIoU、Dice/F1、Precision、Recall、Boundary IoU。
- 斑块级召回和假阳性斑块数。
- 有地理标定时报告覆盖面积绝对误差与相对误差。

### 统计协议

- 以采集组/原始大图为重采样单位做 95% bootstrap CI，不能把高度相关的切片当独立样本。
- 对候选方法与最强基线做配对 bootstrap 差值；同时报告 3 个随机种子的均值和标准差。
- 预先指定主要终点：Track A 为外部测试 Recall@固定 FPPI，Track B 为外部测试 mIoU；其余为次要终点。

## 7. 界面与分析设计

第一版界面包含四页：

1. **识别**：上传单图/批量图，显示框或掩膜、置信度、处理时间。
2. **无人机巡查**：大图切片推理、拼接掩膜、覆盖率/面积、热力图。
3. **误差分析**：TP/FP/FN 浏览，按近似种、物候、尺度、设备筛选。
4. **实验对比**：模型版本、指标、混淆/PR 曲线、速度和模型体积。

所有推理结果保存模型版本、数据版本、阈值和运行配置，保证论文图表、专利实施例和界面展示能追溯到同一实验。

## 8. 论文与专利路径

### 论文主线

论文不以“我们训练了 YOLO”作为贡献，而以以下证据链组织：

1. 构建按采集组隔离、包含近似种和双场景的薇甘菊 RGB 数据协议。
2. 证明形态辅助监督和困难负样本学习对误检/非花期泛化的贡献。
3. 证明近景检测与 UAV 斑块分割在统一系统中的尺度适配和外部泛化。
4. 公开或内部固化可复现实验、误差分析和部署数据。

### 专利候选

初步检索显示薇甘菊 RGB CNN 分类、阈值分割、LiDAR+航拍和多光谱随机森林均已有专利。候选权利要求不能泛写“获取图像—训练模型—识别薇甘菊”，应围绕可验证的技术组合及其效果：

- 形态属性辅助监督与近似种对比约束的协同训练；
- 基于不确定性和近似种风险的主动复核闭环；
- 近景检测与 UAV 斑块分割的跨尺度结果校准和面积输出。

正式撰写前需进行权利要求级检索。依据现行专利法，新颖性以申请日前国内外为公众所知的技术为基准，因此原则上应在论文、答辩材料公开或演示技术细节之前完成申请；这部分需由专利代理师作最终法律判断。

## 9. 里程碑与退出条件

| 阶段 | 建议周期 | 交付物 | 退出条件 |
|---|---:|---|---|
| 试标与审计 | 1–2 周 | 最终标注规范、group 划分、试标报告 | 标注一致性和任务形式确定 |
| 首轮标注与基线 | 2–4 周 | 数据 v1、B0–B3/S0–S2 | 基线可复现、无泄漏 |
| 方法与消融 | 3–6 周 | A1–A6、误差分析 | 至少一个稳定正向结果或停止该假设 |
| 外部测试与部署 | 2–4 周 | 冻结模型、API、界面 | 外部指标和速度达标 |
| 专利/论文 | 与实验并行 | 交底书、论文草稿 | 专利顺序审查完成、证据可追溯 |

若 A1–A6 在分组测试上均不能稳定优于“更多数据 + 更高分辨率”的简单基线，则停止堆叠新模块，转向数据质量、跨地点采集和标注一致性改进。
