薇甘菊智能识别系统 v2.1.0｜零基础快速开始
================================================

您不需要安装 Python，也不需要输入程序命令。

第一次使用
----------
1. 将整个压缩包“全部解压”，不要直接在 ZIP 压缩包中运行文件。
2. 保持电脑联网，并根据电脑系统双击对应的“01-一键安装”文件。
3. 等待窗口显示“安装成功”。首次安装通常需要 5 至 15 分钟。
4. 双击对应的“02-启动识别系统”文件。
5. 浏览器会自动打开 http://127.0.0.1:18080 。

以后使用
--------
只需双击对应的“02-启动识别系统”文件，不必再次安装。

Windows
-------
双击：01-一键安装-Windows.bat
启动：02-启动识别系统-Windows.bat

macOS
-----
首次运行请右键“01-一键安装-macOS.command”，选择“打开”。
安装后双击：02-启动识别系统-macOS.command

Linux
-----
允许脚本作为程序运行后，执行：01-一键安装-Linux.sh
安装后执行：02-启动识别系统-Linux.sh

需要让同一 Wi-Fi 下的手机或其他电脑访问
---------------------------------------
运行对应系统的“03-启动局域网共享”文件，窗口中会显示访问地址。
请勿将该地址直接开放到公网。

打不开网页时
------------
1. 确认启动窗口仍然开着；关闭启动窗口会停止系统。
2. 手动在浏览器输入：http://127.0.0.1:18080
3. 若仍无法打开，关闭所有旧的启动窗口，再重新双击“02-启动识别系统”。
4. 安装失败时窗口不会自动关闭；按提示查看“runtime/logs”文件夹。
5. Windows 可双击“04-Windows故障诊断.bat”，把停留窗口的照片发给技术支持。

代码和模型在哪里
----------------
程序源码：打开“程序源码”文件夹，可看到网页、推理、数据处理和训练代码。
模型文件：打开“模型文件/mikania-yolo26s-v2”，可看到 model.onnx 和 model.pt。
安装脚本：打开“runtime”文件夹，可看到环境安装器、启动器和日志。
完整目录说明见根目录“交付内容与文件清单.txt”。

详细步骤请阅读《薇甘菊识别系统-零基础操作手册》PDF 或 Word 文件。
