# 薇甘菊地面目标检测项目：研究问题卡

版本：v1.0  
日期：2026-08-04  
状态：研究问题已冻结；通过数据质控门后运行正式实验

## Research Question Card

**Question**  
在严格按采集组和近重复簇隔离的数据上，物种分层的困难负样本训练与错误区域挖掘，能否相对现代强基线降低复杂混生植被中的薇甘菊误报，同时保持目标召回率和可部署的推理效率？

**Type**  
应用性研究，包含一个确认性方法比较。

**Hypothesis**

1. COCO 预训练的 YOLO26s-640 可在现有小规模数据上形成稳定的实时检测基线。
2. 经确认的假臭草、三叶鬼针草、火炭母、水蓼、大青叶等近似植物负样本，可明显暴露全正样本测试无法反映的误报问题。
3. 物种分层采样和基于模型误报分数的困难负样本挖掘，可在召回下降不超过 2 个百分点时，使 FPPI 相对下降至少 30%。
4. 当前目标以中大型为主，960 输入或 P2 小目标结构未必优于 640 的精度—速度折中。

**Why it matters**  
实际巡查不仅需要找出薇甘菊，还需要避免把相似植物错误上报。只在含薇甘菊的图片上报告 mAP，不能证明系统在真实混生环境中可靠；困难负样本上的误报控制是本项目从普通模型训练走向论文、专利和部署的关键。

**Current evidence**

- `ER-20260804-detection-dataset-v1-01`（dataset）：已获得 462 张合法标注图和 941 个类别 0 检测框；训练/验证/内部测试/时间外测试分别为 245/61/56/100 张。采集组、近重复和完全重复跨集合均为 0。证据文件：`datasets/mikania_detection_v1/manifests/summary.json`。
- `ER-20260804-target-scale-audit-01`（experiment artifact）：按最长边缩放到 640 后，95% 的目标最短边约不低于 51 像素，仅 8 个目标低于 32 像素。这支持把 640 设为首轮基线，但不能提前断言 640 是最优分辨率。
- `ER-20260804-negative-pool-01`（dataset）：现有 123 张相似植物或背景候选尚待确认；当前 462 张训练就绪图全部包含至少一个正框。因此现在可以做正样本基线，但不能做最终低误报结论。
- `ER-20260804-temporal-test-01`（dataset）：2026 年时间外测试含 100 张图、257 个框，但只有 5 个划分单元且全部来自 Xiaomi 15 Pro。它能支持时间迁移观察，不能支持跨地点或跨设备泛化主张。
- `ER-20260801-patent-landscape-01`（project note）：已有多种薇甘菊 RGB/遥感识别专利，“用深度学习识别薇甘菊”本身不足以构成专利区分点；候选创新需落到困难区域生成、物种分层采样、对比约束和复核回流的具体组合。

**Missing evidence**

- 123 张候选负样本的物种确认结果，以及各近似种在训练/验证/测试中的数量。
- 16 个覆盖面积不低于 90% 的框是否准确，12 张缺标签图的最终标签。
- YOLO26、Faster R-CNN 和 RT-DETRv2 在同一固定划分上的基线结果。
- 困难负样本方法在 3 个随机种子上的稳定性和配对 bootstrap 区间。
- 至少 3 个新地点的地理独立正负样本测试集。
- 候选专利权利要求相对于论文和专利现有技术的逐项检索。

**What would support it**

- A3 困难负样本挖掘相对最强简单基线，在召回下降不超过 2 个百分点时使 FPPI 相对下降至少 30%；或使 Recall@FPPI=0.1 提升至少 3 个百分点。
- 三个随机种子的改进方向一致，主要指标配对 bootstrap 的 95% 置信区间不跨 0。
- 时间外正样本召回没有因加入负样本而明显下降，且 640 下保持可部署延迟。

**What would falsify it**

- 负样本改进只在验证集出现，在冻结测试集消失或反向。
- 误报下降主要来自提高置信度阈值，并伴随超过 2 个百分点的召回损失。
- 困难挖掘没有优于简单混入负样本，或不同种子方向不一致。
- 复杂方法没有优于增加经确认数据、温和增强或 640 强基线。

**Minimal next action**  
完成 16 个超大框复核、12 张缺标签图处理和 123 张候选负样本的三态确认，冻结 `v1.2-hn` 数据版本；随后在远程服务器单卡运行 YOLO26n-640 的 10 轮烟雾测试。

**Decision**  
`run experiment`：采用分阶段门控。当前可运行正样本烟雾测试；低误报正式实验必须等待困难负样本确认。

## Claim limits

- 当前允许表述：“已构建按采集组隔离的薇甘菊地面目标检测数据版本，可开展基线实验。”
- 当前禁止表述：“模型已实现高精度、低误报、跨地点泛化”或“困难负样本方法有效”。这些必须由冻结测试实验支持。
