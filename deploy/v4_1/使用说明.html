薇甘菊识别系统 V4.1

Windows 10/11 · 64 位 x64 · 本机 CPU 离线识别 · 测试交付版

先了解版本边界

已包含模型、Python运行环境和完整网页，无需另外安装Python、Docker或连接VPN。首次运行如缺少微软 Visual C++ 组件，会提示安装包内的官方组件，可能需要管理员确认。建议至少4GB内存及1GB可用磁盘空间。本包尚未完成Windows实机验收，请先在测试电脑验证。EXE不能在macOS/Linux或32位Windows直接运行。

一、安装和第一次运行

  1. 推荐双击 Mikania-Setup-4.1.0.exe，确认安装。等待解压完成，桌面会出现 Mikania V4.1 快捷方式。
  2. 也可以使用ZIP免安装版：右键ZIP → “全部解压缩” → 打开解压后的文件夹 → 双击 Mikania.exe。不要在压缩包内直接运行，也不要只复制一个EXE。
  3. 如果提示缺少运行组件，选择安装，按系统提示确认。组件已附带，无需在线下载安装。若电脑不允许安装，请联系管理员；不要关闭安全软件。
  4. 等待窗口显示“本机地址”，浏览器会自动打开识别网页。请保持程序窗口开启；关闭它会停止识别服务。
  5. 浏览器没有自动打开时，复制窗口中的地址。通常是 http://127.0.0.1:18041，如端口被占用会自动选择18042–18050。不要打开程序里的index.html文件。

安装位置：%LOCALAPPDATA%\Programs\Mikania\4.1.0-20261013。再次安装不会覆盖旧目录；需要重新测试时，可先关闭程序并把旧目录改名留作备份，或换用ZIP解压到新目录。

二、识别照片

  1. 先点击网页中的“地面实景”等示例，将图片加入待识别队列。
  2. 点击开始识别，等待结果出现。实际耗时取决于电脑性能和照片大小。
  3. 拖入或选择你自己的JPG、PNG、WebP照片，每张不超过20MB。
  4. 查看“检出/未检出”、原图与标注图对照。支持批量处理、下载标注图和导出CSV记录。
  5. 测试时先使用默认阈值，不要把网页中的3.9%理解为准确率。刷新网页前先导出结果，当前队列和历史记录保存在页面会话中。

三、怎样理解结果

V4.1偏重减少漏检，不代表所有照片都能准确识别。已有地面评估74张中检出54/56张阳性，18张阴性误报4张（22.2%）；外部阳性照片98/100检出，无人机阳性照片42/43检出。后两组没有阴性，不能用作总体准确率。

这些是已使用过的开发/评估数据，不是新采集盲测。绿色区域是粗略定位参考，不是精确目标边界，不能保证覆盖所有薇甘菊。阳性和阴性结果都应结合人工复核。

四、常见问题

  • 双击后没有网页：看程序窗口是否提示模型加载或错误；按上面的本机地址手动打开。
  • “无法访问此网站”：确认Mikania程序窗口还开着，使用窗口显示的当前地址。离线版不需要训练服务器在线，也不需要VPN。
  • 模型缺失：重新完整解压；不要移动或删掉 models、runtime、app。
  • 系统安全提示：本测试包未做商业代码签名，系统可能提示未知发布者。先核对来源与SHA256；如单位策略禁止，请联系管理员，不要关闭系统保护。
  • 截图反馈：提供Windows版本、错误截图、出问题的原照片以及日志。日志地址 %LOCALAPPDATA%\Mikania\4.1\logs，可复制到资源管理器地址栏打开。安装失败另查 %TEMP%\mikania-install-error.txt。

五、包里有什么

models：两个ONNX模型及精确配置；runtime：内置运行时和依赖；app：网页与推理源码；developer：原始PT权重、导出/构建源码、测试和数值验证报告。

为便于复制，本运行包不包含全部原始训练图片和标注数据；之前的完整研发数据交付保留。全部照片在本机处理，不会自动上传训练服务器。没有自动更新、开机启动或后台遥测。

卸载：关闭程序，删除本版本安装目录及桌面快捷方式即可；日志单独保留。微软共享运行组件不应随意卸载。
