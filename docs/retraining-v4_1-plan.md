# V4.1：按用户更正标签后的无人机联合训练

日期：2026-09-14。用户最新说明：“应该无人机照片中没有不含薇甘菊图片的，全部都是薇甘菊。”本轮以这条最新说明替代此前“混有整图阴性”的数据假设。

## 标签与用途

- 375 张 UAV 均作为用户提供的照片级阳性标签，来源 `user_reported_positive`，不是植物专家逐图认证。保留助手原始初筛标签以供追溯。
- 既有照片分组不变：UAV 训练 278、验证 54、留出 43；不会为了增加训练量重新随机分组。
- 显式正/负局部区域仍标为助手初筛来源。整图阳性不意味着每个局部阳性；新增 146 张不得自动派生全图阳性瓦片。
- 地面 585 张及其他植物正负划分不变。V4 数据、结果、模型保留原样；新建 V4.1 数据版本。
- UAV 仍没有整图阴性，所以不能测 UAV 整图误报率。地面阴性用于地面误报检查，不能冒充航拍阴性。

## 本轮预定义实验（评分前冻结）

1. H1：与 V4 G1 相同通用 YOLO26s-cls 初始化、整图 512、lr 0.001，其余配置与 V4 相同，只改变 UAV 标签覆盖。
2. H2：V4 G1 整图权重初始化，用新数据低学习率 0.0002 微调，整图 512。输入权重只接触过原训练子集。
3. 局部分支固定 V4 G3；没有新增局部标注，避免无效重复训练和把无目标背景标为阳性。
4. 仅在验证集比较两个预定义决策：`0.25×scene + 0.75×patch_second`；`min(scene, patch_second)`。后一种要求整图和局部证据同时达到阈值，检验单一分支触发误报的问题。
5. 每个有负样本的验证域，图片误报率和拍摄组平均误报率都要求为 0，再最大化域/正拍摄组等权召回；同规则并列取较高阈值，规则并列优先双证据 min 门控，同分模型按 H1、H2 顺序。零验证误报不是总体误报率为零的承诺。
6. 冻结一个模型和阈值后才评分回归/留出集合；不因某个候选回归更好而重新选阈值或替换候选。

## 评价与上线门槛

固定旧 V3 阈值 0.88，在相同新清单复测。与 V3 比较内部地面 TP/FP、外部 100 张阳性检出，以及 43 张 UAV 用户提供阳性标签上的检出。上线前仍要求地面误报不增加、上述阳性检出不下降；否则保留 V3。

旧内部与外部集合已用于历史方案分析；V4 的 24 张 UAV 留出也已公开结果。新加入的 19 张 UAV 留出来自相同冻结拍摄分组，不能假装 43 张全是首次盲测，所有结果作研发回归用途。本轮门控假设受到 V4 错误分析启发，也不声称它在一个从未使用过的测试集上得到证明。必须另外采集跨地点正负盲测集，才可形成最终论文泛化结论。
