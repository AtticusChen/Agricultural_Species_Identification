## 这次改了什么

- 重新设计电脑端工作台：森林绿导航、真实植物照片、统一的上传与结果区域。
- 支持最多10张照片顺序识别、暂停后继续、失败重试；每张20MB，总计80MB。
- 原图、识别参考图与并排对比；放大查看、保存真实结果图。
- 当前会话记录、搜索与结果筛选，支持带中文表头的CSV导出。
- 内置地面、航拍、其他植物三张真实示例；图片与缩略图去除EXIF，地面示例水印中的坐标/时间已脱敏，原始数据不改。
- 常用操作前置，阈值收进高级设置，默认使用服务器的精确推荐值。
- 服务离线、图片损坏、失败与未检出分开呈现；不把模型得分写成准确率。
- 使用指南直接放在页面里。用户明确不需要手机布局，只针对电脑与笔记本验收。

## 模型和研发代码边界

本次只改网页，不声称提升模型精度。生产仍为 `mikania-ensemble-v3`、阈值0.88、precise模式。V4.1未通过误报上线门槛，未部署。

生产后端从服务器原版本派生，绝不以本地较新的研发 `predictor.py` 替换服务器。最小后端变化仅为：示例入口、首页重新验证缓存、显式阈值范围0..1。原模型构造、默认值校验、健康接口与预测函数主体不变。两个模型权重和服务配置保留。

旧V3接口不提供照片级得分，因此新版如实显示“—”，悬停说明未提供；不会用局部区域最高概率冒充整图得分。绿色框仍是粗粒度支持区域，不是完整植株轮廓，也不是植株数量。
