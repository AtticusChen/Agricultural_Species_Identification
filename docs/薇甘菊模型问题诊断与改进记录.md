> 本文档用于记录用户反馈的漏检、误检和检测不完整问题，以及后续的诊断证据、实验设计和修复结果。

## 诊断结果

1. 当前模型验证 Recall 仅 0.380，mAP50–95 仅 0.176，尚不是高可靠交付模型。
2. 462 张训练就绪图像全部是正样本，训练中没有非薇甘菊空标签图像。
3. `IMG_20251118_121305` 与数据目录中的假臭草样本一致，但被错误标成 3 个 mikania 框并进入训练集。
4. 用户指出的四张正样本存在漏标或框选规则不一致，模型无法从不完整监督中学会覆盖全部区域。
5. 4096 像素级原图缩小至 640 时丢失细节；1280 重叠切片能恢复两张原本 0 检出图的候选框，但同时将假臭草误检从 1 个放大到 11 个。

结论：根因优先级为“错标/漏标 > 缺少负样本 > 整图缩放 > 模型与训练配置”。
